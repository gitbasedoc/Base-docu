┌───────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 1 : CONFIGURER LE DNS                                         │
└───────────────────────────────────────────────────────────────────────┘

  Créez cet enregistrement DNS chez votre fournisseur :

  ┌─────────────────────────────────────────────┐
  │  Type      : A                              │
  │  Nom       : gagneraud                      │
  │  Domaine   : basedoc.fr                     │
  │  Cible/IP  : 193.70.41.117                  │
  │  TTL       : 3600 (ou Auto)                 │
  └─────────────────────────────────────────────┘

  Résultat : gagneraud.basedoc.fr → 193.70.41.117

┌───────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 2 : VÉRIFIER LA PROPAGATION (attendre 5-30 min)               │
└───────────────────────────────────────────────────────────────────────┘

  Depuis votre terminal :

    nslookup gagneraud.basedoc.fr

  Ou en ligne :

    https://dnschecker.org/#A/gagneraud.basedoc.fr

  ✅ Vous devez voir : 193.70.41.117

┌───────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 3 : OBTENIR LE CERTIFICAT SSL                                 │
└───────────────────────────────────────────────────────────────────────┘

  Connectez-vous au serveur :

    ssh ubuntu@193.70.41.117

  Lancez Certbot :

    sudo certbot --nginx -d gagneraud.basedoc.fr \
      --non-interactive --agree-tos \
      --email dheurtebise@basedoc.fr --redirect

  ✅ Succès si vous voyez :
     "Congratulations! You have successfully enabled HTTPS"

┌───────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 4 : TESTER L'APPLICATION                                      │
└───────────────────────────────────────────────────────────────────────┘

  Ouvrez votre navigateur :

    https://gagneraud.basedoc.fr

  ✅ Vous devriez voir la page de login avec le cadenas 🔒

  Connectez-vous avec :
    Email : dheurtebise@basedoc.fr
    Mot de passe : [celui que vous avez défini]
